## Перевірки з етапу 1

### 4. Прив'язка чатів

**Дія**: у застосунку розділ «Сім'я» → згенерувати код й надіслати його:
- Один з особистого чату першої людини: `/start КОД`.
- Один з особистого чату другої людини: `/start КОД`.
- Один у сімейну групу: `/start КОД` (посилання `?startgroup=`).

**Очікування**: усі три чати показуються як прив'язані.

| Дата | Результат | Що не так |
|------|-----------|----------|
|      |           |          |

### 5. Відв'язка одного чату

**Дія**: у застосунку нажати на іконку відв'язання для одного з трьох чатів (наприклад, першого особистого).

**Очікування**: 
- Чат відв'язується.
- Інші два чати залишаються прив'язані й можуть надсилати скани (перевірити швидким запитом у групі).

| Дата | Результат | Що не так |
|------|-----------|----------|
|      |           |          |

**Очікування**: бот не реагує (немає відповіді).

| Дата | Результат | Що не так |

|      |           |          |

### 7. Обробка медіа, команди, швидких запитів, згадок у групі

**Дія** (кожне окремо):
- Надіслати фото чека.
- Надіслати команду `/start`.
- Надіслати швидкий запит «Список покупок» (не повинен видати результат, якщо це не те, що очікується).
- Надіслати повідомлення зі згадкою `@CookingFamilyBot`.

**Очікування**: бот обробляє кожне дію (відповідає на медіа, команди, запити, згадки).
