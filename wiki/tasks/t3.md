PR: https://github.com/sashakuzmenko-ai/buycookeat/pull/2

## What changed

Single migration `supabase/migrations/20261112000000_scan_receipts_stock.sql` adds:

1. **Pantry enhancements**: `storage_zone` (fridge/freezer/pantry, default pantry) and `expires_at` (nullable date) columns on `pantry_items`.
2. **Pantry movements log** (`pantry_movements`): tracks every stock change with source (scan/cooked/inventory/manual) and optional scan/meal_plan reference.
3. **Family member dietary data**: `restrictions text[]` on `family_members`.
4. **Monthly budget**: `monthly_budget` column on `households`.
5. **Receipts** (`receipts` + `receipt_items`): store reference, purchase date, total, input source, scan link.
6. **Incoming scans** (`incoming_scans`): channel, input type, status, mode (add/set), recognized items as JSONB, channel metadata.
7. **Channel bindings** (`channel_bindings`): maps external chat IDs to household+user with one-time link code and expiry.
8. **`adjust_pantry` updated** to log movements automatically; existing callers unaffected (same signature).
9. **`confirm_scan(uuid)` function**: atomically increases stock + logs movements + creates receipt (add mode) or sets stock (set mode), marks scan confirmed. Security invoker.
10. **RLS** on all new tables via `is_household_member`, indexes on `household_id` + date columns, grant/revoke on functions.
