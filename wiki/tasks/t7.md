## Fix T1-f2: SonarCloud Security Rating (PR #25)

- **Причина**: після manual redirect Quality Gate далі падав із **Security Rating B** на новому коді — Sonar S5144 (SSRF) не вважає синтаксичну фільтрацію hostname достатньою без перевірки резолву DNS.

- **Gate**: `npm run lint`, `npm run check`, `npm run build` — pass. SonarCloud на PR після push очікується **≥ A** на новому коді.
